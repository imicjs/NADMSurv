# MICCAI2026 - NADMSurv

This project is a codebase for paper entitled: "Noise-Aware Importance–Uncertainty Disentangled Multimodal Learning for Robust Cancer Survival Prediction" which is accepted by MICCAI 2026. It includes modules for data processing, model training, and downstream tasks.

## Project Layout

```
- Python >= 3.9
- CUDA >= 11.8 (for GPU acceleration)
- Install dependencies: `pip install -r requirements.txt`
```



## Configuration

All paths and hyperparameters are centralized in configs/config.yaml. Modify the root field to match your local environment before running.



## Main Modules

- `src/preprocessing/`: Data preprocessing pipelines for mRNA and WSI modalities.

- `src/models/`: Core deep learning architectures.
  - `decoupled_model.py`: Noise-aware disentanglement mechanism .
  - `hypergraph_fusion.py`: Evidential hypergraph neural networks with subjective logic fusion .

- `configs/`: Centralized experiment configuration.
  
  - `config.yaml`: All file paths, directory roots, and hyperparameters.
  
- `data/raw/`: Original multimodal inputs.

- `data/processed/`: Generated intermediate files.

  

## Quick Start

Survival prediction, the following files are required:

- `data/raw/genomics/Cancer_clinical.csv`
- `data/processed/decoupled/Cancer_decoupled_representations.h5`

All intermediate files under `data/processed/genomics/` and `data/processed/pathology/` can be regenerated.

Run the survival prediction module directly:

```bash
python src/models/hypergraph_fusion.py
```
